知识是网状的，多维度的。即某一类知识通常存在多种框架、多种角度的理解。知识与知识之间也会存在着多种多样的联系，这些联系构成了非常复杂的网状知识库，它很难使用层级式的方式来管理。

为了帮助大家建立起自己的网状知识库，Lattics 提供了多种方法：

1. Tag 标签

<Video src="/images/tag.mp4" width={80}></Video>

Tag 是被广泛使用的知识关联方法。它需要人工标记。标记为同样 Tag 的文章，会被认为属于同一类别，即使文章不在同一个项目，也可以通过 Tag 检索到，从而构建出跨项目的知识联系。

在 Lattics 的文章和卡片的扩展信息界面中，可为文章和卡片标记 Tag；也可在文章正文中使用 #Tag 标签名 的语法来标记，在正文中标记的 Tag 会成为正文内容的一部分。

**提示：**当点击 Tag 标签时，会展开 Tag 图谱，以查看该 Tag 中的所有文章和卡片。

2. 内容引用

<Video src="/images/cite.mp4" width={80}></Video>

知识经常会互相嵌入，比如 A 概念会涉及 B 概念，B 概念会涉及 C 概念... 如同 Wiki 百科 的词条，通过完善各个词条和词条之间的相互连接，就可以轻松构建出一个庞大的知识库。

Lattics 提供了一种内容引用的方法，它可以让 Lattics 中的文章和卡片在本地即可建立相互连接，而无需依赖网络服务。当需要引用某篇文章或者卡片时，只需在正文中输入 @ 。也可从项目大纲、卡片库、搜索结果中拖拽文章和卡片到正文中。

Lattics 提供的引用方式有两种，一种是标题引用，它就像 Wiki 词条，点击即可查看词条的内容。正文中的引用标题可以随意修改，以适应不同的撰文场景；另一种是全文引用，它非常适合用来重复引用某些名人名言、经典诗歌的全文内容，并与原文的样式保持一致。在修改原文时，相应的全文引用内容也会自动更新，省却了校订的麻烦。

标题引用和全文引用可以很方便地相互转换，只需点击引用弹窗左下角的转换按钮即可。全文引用也可以通过点击弹窗右上角的“取消引用”而变成一段纯文本文字。

**提示：**在写作过程中如需把某段文字或者某个关键词转为可复用的卡片或词条，可以先选中这些文字，然后在右键菜单中点击“转为卡片”即可。如果某个关键词已经有相关词条，则会自动建立对该词条的引用，非常方便。

3. 后向链接 与 待链接

   如果文章或者卡片曾被引用过，那么在它们的扩展界面中会列出引用过它们的文章（后向链接），点击链接即可查看和编辑引用了它们的文章正文。

   Lattics 提供了 “待链接” 的功能。会罗列出所有提及过该词条，但尚未引用过它的文章和卡片，可一键建立引用连接，大大提高建立网状知识库的效率。

4. 知识图谱

<Video src="/images/graph_switch.mp4" width={80}></Video>

对于网状的知识库，最好的查看方式就是图谱。Lattics 提供了三种非常实用的图谱：

1.  思维导图

    思维导图非常适合用来构思写作思路。在刚开始写作时，通过思维导图可以快速建立项目大纲。在思维导图中显示的是各个节点的标题，如果需要编辑节点的正文，可在右键菜单中找到编辑功能，也可使用快捷键 Ctrl + E / Cmd + E 快速打开正文。

    **提示：**思维导图的节点层级和位置是与项目大纲实时同步的，即调整思维导图的节点位置，项目大纲会随之更新，反之也是，项目大纲的文章位置发生了变化和调整，也会在思维导图中反映出来。

2.  情节视图

    情节视图非常适合用来构思各章节的写作要点和主要情节，并且帮助整体设计各章节之间的情节发展和叙事方式。情节要点的内容将记录在文章的备注信息中，并不会影响正文。

3.  鸟瞰视图

    鸟瞰视图非常适合用来最后打磨和概览写作项目。它会把所有文章和卡片的内容以缩略的方式展示在图谱上，也会把文章和卡片之间所有的关系都呈现出来，包括引用关系，关联关系。在鸟瞰视图中，可通过右键菜单中的拖拽箭头，建立两篇文章之间的关联关系，并可为关系连线设置不同的颜色，线型，以及标记关系名称。

    鸟瞰视图可以拖拽每个文章或卡片的右下角，改变它们的显示大小，以方便针对不同的内容展示需求。

    **提示：**思维导图、情节视图、鸟瞰视图 都可对每个节点设置颜色，以标记文章的重要性或者优先级。也可以移除和删除某个节点，这些功能都在节点的右键菜单中。

4.  智能联想

    在写作的过程中，Lattics 会根据输入的内容自动检测已有的词条，并显示出筛选后的列表，以方便快速建立引用关系。
