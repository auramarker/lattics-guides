在写作论文和研究报告时，经常需要引用其他论文或书籍，而严肃的学术期刊也都各自对参考文献样式制定了不同的规范要求。因此，编辑、调整、校对、排版参考文献内容和样式，往往会占去论文和报告写作的许多时间，而这些工作对论文写作而言其实并没有太多的实质价值， 更应该自动化地完成才好。

为此，Lattics 创新的设计和开发了参考文献的管理、编辑、引用和自动排版功能，它会大大提升论文和报告写作引用文献的效率。

1. **创建参考文献：**

   参考文献的格式非常多，比较常用的包括 BibTex，RIS，EndNote，这些在学术期刊网站或者预印本网站上很容易获取。

   在网页上复制它们，然后在 Lattics 的项目大纲中，创建新的参考文献，将文本信息粘贴到编辑弹窗中，当内容识别为所支持的参考文献内容格式时，就可以保存它为 Bib 文件了

   Lattics 会自动解析并创建参考文献信息中的字段，比如标题、作者、关键词、出版类型、出版时间、DOI、ISBN、PMID、arXiv 等 id 号码，方便以后去重和准确检索相应的文献。
   <Video src="/images/bib/new_bib.webm" />

2. **导入参考文献：**

   可以批量导入参考文献的文件，把它们拖拽到项目大纲中即可，也可通过项目大纲的导入功能。目前支持的参考文献格式为：BibTex，RIS，EndNote 三种。

3. **管理参考文献：**

   创建与导入的参考文献，可以像其他文件一样管理，可以在项目大纲和图谱中拖拽调整层级位置，也可以为它们标记 Tag（关键词），通过 Tag 进行管理。

4. **PDF 元数据：**

   Lattics 可以自动从 PDF 文件中读取出它的元数据作为参考文献的字段，通常标题、作者都是可以获取到的，而 DOl、arXiv 等 ID 信息需要自己补全一下。可以在 PDF 扩展信息界面中补充和编辑。

5. **将 PDF 内容摘录为卡片：**

   在 Lattics 中打开 PDF，可以选中其中的部分文字，将其创建为卡片。

   通过 PDF 摘录创建的卡片，其扩展信息中将会带有 PDF 链接信息，点击该链接，可以打开 PDF 并定位到摘录的页面位置。
   <Video src="/images/bib/pdf_locate.webm" />

6. **文章中引用参考文献：**

   参考文献可以在文章或者卡片中使用 @引用。

7. **在文章中插入参考文献模块元素：**

   在文章中通过 / 快捷键可以添加参考文献块元素。添加了参考文献块元素之后，文章中如果有参考文献出处的引用，都会自动以参考文献的方式显示，比如摘录自 PDF 的卡片， 有元数据的 PDF 文件，参考文献等。

   在编辑文章的过程中，当引用的位置发生了变化，参考文献的列表序号也会自动调整，引用的编号也会自动更新。

   参考文献的样式可以自由调整，Lattics 内置了 10 多种常见的期刊 CSL 样式，可以在文献块元素中进行切换，切换后，正文中各引用的样式也会自动更新。

   参考文献块元素可以转为正文，以方便文字编辑和校对。

   <Video src="/images/bib/auto_bib.webm" />

8. **自定义参考文献模块和样式：**
   期刊非常多，我们无法一一制作它们的参考文献样式，因此 Lattics 采用了 CSL 文献规范，你可以自己下载更多的 CSL 文献模版导入到 Lattics 中，也可以参考某个 CSL 模版，修改其中的 XML 参数，制定自己的参考文献样式。

   <Video src="/images/bib/import_csl.webm" />
