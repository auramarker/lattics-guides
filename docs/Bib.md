在写作论文和研究报告时，经常需要引用其他论文或书籍，而严肃的学术期刊也都各自对参考文献样式制定了不同的规范要求。因此，引用、管理、编辑参考文献内容和样式，往往会占去论文和报告写作的许多时间，而这些工作对论文写作而言并没有实质价值，应该自动化地完成才好。

为此，Lattics 创新的支持了五种摘录和引用参考文献的方式，并提供了自动化生成参考文献列表的功能，它们会大大提升论文和报告写作引用文献的效率。

1. **从 Zotero 中复制和拖拽所需引用的内容**

   Zotero 是被广泛使用的参考文献管理应用，可以使用它高亮标记 PDF 论文，可以做笔记。当安装了 Lattics for Zotero 插件之后，即可从 Zotero 中，将 note 或 PDF 高亮内容复制和拖拽到 Lattics 文档中，作为引用，同时会带上参考文献的元数据。具体使用方法，可以参考使用指南的“Zotero”一节，也可观看 Lattics 官网提供的视频教程
2. **将 PDF 内容摘录为卡片，并在文章中引用**

   先将 PDF 文件拖拽或导入到项目大纲中，如果 PDF 文件携带有文献元数据，Lattics 就会自动从中解析出来，如果 PDF 文件缺失文献元数据。则可以在 PDF 文件的扩展信息界面中补充和编辑，比如标题、作者、期刊名称、出版日期、DOI 等信息均可手动添加和编辑

   然后，在 Lattics 中打开 PDF 阅读，在阅读过程中，可以选中部分内容摘录为卡片，这些卡片会自动带上该文献的元数据，并记录所在页码，在卡片的扩展信息界面中，会在后向链接中显示该 PDF 的链接，点击该链接，可以打开该 PDF 并定位到相应的页面位置

   最后，将卡片从卡片库拖拽到文档中，或者直接使用 @ 在文档中引用即可
   <Video src="/images/bib/pdf_locate.webm" />

3. **直接引用 PDF 文件或参考文献文件**

   在导入 PDF 文件后，可以将 PDF 直接拖拽到 Lattics 文档中，或者通过 @ 引用 PDF 文件，如果 PDF 文件带有元数据，则也可以列入参考文献

   有时候，可能无法获得文献的 PDF 文件，但是可以获得其文献元数据，比如 BibTex，RIS，EndNote 格式的参考文献信息，这些在学术期刊网站或者预印本网站上很容易获取。Lattics 支持创建和导入这些参考文献文件。在 Lattics 中创建参考文献文件的方法是：在网页上复制它 BibTex，RIS，EndNote  格式的文献信息，然后在 Lattics 的项目大纲中，创建新的参考文献，将文本信息粘贴到编辑弹窗中，当内容识别为所支持的参考文献内容格式时，就可以保存它为 Bib 文件了。Lattics 会自动解析并创建参考文献信息中的字段，比如标题、作者、关键词、出版类型、出版时间、DOI、ISBN、PMID、arXiv 等 id 号码，方便以后去重和准确检索相应的文献。

   也可以批量导入参考文献的文件，把它们拖拽到项目大纲中即可。目前支持的参考文献格式为： BibTex，RIS，EndNote 三种。创建与导入的参考文献，也可以像 PDF 文件一样，拖拽到 Lattics 文档中，或者使用 @ 引用即可
   <Video src="/images/bib/new_bib.webm" />

4. **在 Web app 中摘录为卡片，并在文章中引用**

   网页内容也是参考文献的来源之一，在 Lattics 中，可以打开 Web app，访问相应的网页，在页面中选中部分内容，可以直接拖拽到 Lattics 文档中，或者摘录为卡片，再在文档中引用。 Lattics 会自动为该卡片创建元数据，包括文章标题，作者，URL，文章发布时间，访问时间等
5. **直接创建卡片，为卡片手动补充元数据**

   有些情况下，可能无法获得文献的原文件，源地址，只有曾经摘录的片段内容。此时，只需要在 Lattics 中创建一个卡片，并在卡片的扩展信息界面中补充其中的元数据，比如标题、作者、期刊名称、出版时间等，即可在文档中作为参考文献引用它们

以上五种方法是在文档中添加文献引用的方式，要在文档中自动创建参考文献列表，还需要添加参考文献块元素，并调整所需的参考文献样式：

1. **添加参考文献块元素**

   在文章中需要显示参考文献列表的位置，通过 /  快捷键添加参考文献块元素。添加了参考文献块元素之后，文章中已经添加了的文献引用，就会自动以参考文献的样式显示。在编辑文章的过程中，当文献引用的位置发生了变化，参考文献的列表序号也会自动调整，引用的编号也会自动更新

   参考文献的样式可以自由调整，Lattics 内置了 10多种常见的期刊 CSL 样式，可以在参考文献块元素中一键切换，切换后，正文中各文献引用的样式也会自动刷新。

   参考文献块元素可以转为正文，以方便文字编辑和校对

   <Video src="/images/bib/auto_bib.mp4" />

2. **自定义参考文献模版和样式**：

   期刊非常多，我们无法一一制作它们的参考文献样式，因此 Lattics 采用了 CSL 文献规范，你可以自己下载更多的 CSL 文献模版导入到 Lattics 中，也可以参考某个 CSL 模版，修改其中的 XML 参数，制定自己的参考文献样式

   英文 CSL 模版下载：[https://github.com/citation-style-language/styles](https://github.com/citation-style-language/styles)

   中文 CSL 模版下载：[https://zotero-chinese.com/styles/](https://zotero-chinese.com/styles/)

   <Video src="/images/bib/import_csl.webm" />

**特别注意：**

1. **在脚注中显示参考文献列表**

   与 Word，WPS 等传统的文本编辑器不同，如果要在脚注中显示文献，只需要在参考文献块元素中选择 note 类型的 CSL 样式即可，在 Lattics 内置的 CSL 模版中，Bluebook Law Review 和 China Nations Standard GB T 7714-2015 note 两种既是此类。中国国内法律界各大院校和期刊的 CSL 模版也都属于此类

   切换为 note 类型的 CSL 样式之后，在导出 PDF 或 Word 文件时，Lattics 就会自动计算，将参考文献显示在每页文章的底部或者文章末尾处，这取决于导出 PDF 或 Word 文件时，所选择的脚注显示的位置
2. **在脚注和文末同时显示参考文献列表**

   在有些特别情况下，如果需要在每页底部和文章末尾都需要显示参考文献列表，也需要选择 note 类型的 CSL 样式，同时在导出 PDF 和 Word 的界面中，设置脚注的位置为“**文页底部 & 文档末尾**“即可

以上，是在 Lattics 添加、管理和编辑文献引用，及参考文献列表的方法，它们比传统的 Word，WPS 更为便捷，因为所有都是自动化的，只需要拖拽就可以完成，而参考文献列表的样式切换，序号刷新，全部都是自动的，无需手动触发任何多余操作。
