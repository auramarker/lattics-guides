为了提高一些常用操作的效率，Lattics 提供了如下一些快捷操作：

1. 项目大纲的快捷键

   调整文章所在层级： 

   新建： 回车

   缩进一级： Tab

   提升一级： Shift + Tab

   删除： Ctrl + D / Cmd + D
   
   移除： Ctrl + Shift + D / Cmd + Shift + D

   上一个/下一个： 上下箭头

2. 主界面的快捷键：

   新建卡片： Ctrl + N / Cmd + N

   全文搜索： Ctrl + Shift + S / Cmd + Shift + S

   展开 / 收起附加信息：Ctrl + Shift + I / Cmd + Shift + I

   展开 / 收起卡片库：Ctrl + L / Cmd + L

   展开 / 收起项目列表： Ctrl + P / Cmd + P

3. 图谱的快捷键

   调节画布的显示比例： 双指放大 / 缩小

   新建：回车

   新建子节点： Tab

   打开编辑器： Ctrl + E / Cmd + E

   删除节点： Ctrl + D / Cmd + D

   移除节点： Ctrl + Shift + D /  Cmd + Shift + D

   切换视图：Ctrl + M / Cmd + M

   展开 / 收起卡片库： Ctrl + L / Ctrl + L

   展开 / 收起项目列表： Ctrl + P / Cmd + P

4. 编辑器中的快捷键（包括主编辑器和弹窗编辑器）

   调节正文内容的显示比例： 双指放大 / 缩小

   加粗： Ctrl + B / Cmd + B

   斜体： Ctrl + I / Cmd + I

   下划线： Ctrl + U / Cmd + U

   删除线： Ctrl + D / Cmd + D

   高亮： Ctrl + M / Cmd + M

   全选： Ctrl + A / Cmd + A

   复制： Ctrl + C / Cmd + C

   粘贴： Ctrl + V / Cmd + V

   剪切： Ctrl + X / Cmd + X

   撤销： Ctrl + Z / Cmd + Z

   样式上下文菜单：Ctrl + T / Cmd + T

   格式刷：Ctrl + F / Cmd + F

   标题：Ctrl + 1-6 / Cmd + 1-6

   引用段落： Ctrl + Shift + .

   符号列表： Ctrl + Shift + 8

   数字列表： Ctrl + Shift + 9

   代码块： Ctrl + Shift + \

   查找替换： Ctrl + S / Cmd + S

   打开 / 关闭扩展信息：Ctrl + I  / Cmd + I
