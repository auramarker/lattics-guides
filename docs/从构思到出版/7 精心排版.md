在完成了所有写作之后，就需要对内容进行精心排版了。Lattics 提供了一些排版工具：

1. 样式设置

   <Video src="/images/styleSetting.mp4" width={80}></Video>

   选中一段文字，右键菜单中会有很多样式设置的功能，包括字体、字号、字体颜色、高亮色、对齐、加粗等等。具体可以查看前文《样式设置》的介绍。

2. 段落样式转换

   <Video src="/images/convert.mp4" width={80}></Video>

   文字的段落内容有着多种样式，比如标题、正文、列表、引用等等。Lattics 提供了一种将文字段落在不同的样式之间转换的方式。比如将正文转为标题，将列表转为正文等等。具体方法是：点击正文段落左上角的操作图标，在菜单的顶部会有“转为”的选项。

3. 图文多栏排版

   <Video src="/images/duoColumn.mp4" width={80}></Video>

   Lattics 支持 3 栏排版。通过拖拽段落、图片等块元素，可以轻松完成多栏排版，同时还可以调节每栏的宽度。具体可以查看前文《图文多栏排版》的介绍。

4. 图片调整

   <Video src="/images/imagescale.mp4" width={80}></Video>

   在正文中，可以拖拽图片的四角缩放图片的大小，也可以在图片底部添加标题。将来，还将会支持图片的裁剪和放大查看等功能，敬请期待...

5. 样式模版

   <Video src="/images/template.mp4" width={80}></Video>

   样式模版是非常强大和实用的功能。如果你有自己比较固定的文章样式风格，可以为文章的各个块元素设计样式的细节，然后保存为模版。具体可以查看前文《样式模版》的介绍。
