对于涉及化学、材料科学、医药等领域的写作来说，化学公式，化学结构式是必然需要的。

在化学方程式方面，Lattics 选择支持了 LaTex 的 mhchem 包，你可以直接输入 LaTex 语法，以及 \ce \pu 两类化学公式，比如：`2H_2 + O_2 \xrightarrow{n,m}2H_2O` 将会显示如下

<Image src="/images/chem/chem-1.png" width={80}></Image>

而 `\ce{KCr(SO4)2 * 12H2O}` 将会显示为：

<Image src="/images/chem/chem-2.png" width={80}></Image>

化学公式还可添加在行内，比如：$2H_2 + O_2 \xrightarrow{n,m}2H_2O
$ 和 $\ce{KCr(SO4)2 * 12H2O}$ 。行内的化学公式，默认是字号的 120% 高，当调整样式模版的字号时，相应块元素的化学公式将会自动调整高度，以与正文的字号相协调

在化学结构式上，Lattics 支持的是 chemfig，比如`\chemfig{[,0.7]*6(-=(*5(-N(-H)-=(-[:30]CH_2CH_2NHCOCH_3)--))-=-(-H_3CO)=)}` 将会显示如下：

<Image src="/images/chem/chem-3.png" width={80}></Image>

在样式模版中，你也可以为化学方程式设定字号，颜色，对齐方式，并且它与数学公式共用同样的样式

<Image src="/images/chem/No-669-image.png" width={80}></Image>

注意：

1. 创建化学公式和结构式的方法如数学公式一样，有两种方法，通过 / 菜单选项，或者输入 LeTex 语法 `$ $` 即可
2. <Color color="Red">化学结构式并不能在行内显示</Color>，只能新起一个段落创建化学结构式
