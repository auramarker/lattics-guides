Lattics 深度集成了 Zotero，你可以将 Zotero 的 note 通过拖拽或者复制到 Lattics 中 ，会自动携带其引用源链接，点击链接可以打开 Zotero 软件，浏览对应的 PDF 和相关标注的位置。
<Image  src="/images/zotero_link.jpg" width={80}/>
安装 Better BibTex 插件后，还可以自动从 Zotero 获取 note 的参考文献元数据，自动生成参考文献列表，切换参考文献的 CSL 样式时，也会自动改变引用样式，极大提升写论文的效率。
