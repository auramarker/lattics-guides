Lattics 为每篇文章，卡片，PDF 都提供了扩展界面，在编辑器的右上角的 i 图标即是，点击它即可查看扩展界面中的信息，你也可以点击其中右上角的锚钉图标，将扩展界面锚定在主界面右侧的 Dock 栏中，以始终展开扩展界面，方便经常查看。

扩展界面中会显示三类信息：

1. 该文章所属的项目，Tag，备忘信息

   在扩展信息中，你可以很容易的为文章添加或删除其所属的项目和Tag，每篇文章都可以归属多个项目，多个 Tag
2. 该文章与其他文章内容的关系，前向链接，后向链接，未链接

   前向链接中会显示该文章所引用的其他文章，后向链接中会显示引用了该文章的其他文章，未链接则显示提到过当前文章标题的文章，可以通过“链接”按钮，快速建立引用关系

   <Image src="/images/addi-info/No-347-image.png" width={35} widthSm={75}></Image>

3. 如果是 PDF 文件，也会显示该文件的文献元数据，比如论文标题，作者，出版年份等

   如果 PDF 文件本身携带有元数据，此处就会自动解析并显示出来，也可以手动补充和修改这些元数据。这些元数据也将是参考文献块元素中会用到的信息
