现在有越来越多的信息与资料是通过网页访问的，比如源自某篇文章的报道，或者某篇博客的分析，这些文章本身就很具有信源价值，已经越来越多成为参考文献的来源，另外，还有一些应用是支持网络版本的，比如 Notion，ReadWise 等，以及许多 AI 应用，比如 DeepSeek，ChatGPT ，如果可以在应用中直接集成一个 Web 浏览器，就可以将它们直接对接在应用中，通过拖拽就可以完成内容的互通，这将会非常强大而便利了

Lattics 为此专门设计和开发了一款简洁的 Web App，它的主要功能和用途有如下几点：

1. **可访问任何网站和网页内容**，只需输入网址即可

2. **书签**，方便经常访问常用的网站

3. **摘录网页 和在线 PDF，自动生成参考文献数据**，并可回溯引用源

   选择网页和在线 PDF 中的部分内容，将它**转为卡片**，此时会**自动记录**此网页的标题，作者，文章发表时间，链接，**摘录的锚点** 等信息到卡片的**元数据**中。当在文章中引用此卡片时，将自动生成参考文献的引用信息。也可以通过摘录的卡片回溯，打开此网页和在线 PDF 相应摘录的位置 （**就像使用 PDF 摘录一样）**

   在线 PDF 还支持 OCR 识别，可以将 PDF 中的表格、数学公式等内容准确提取，保存为卡片

4. **与网页应用之间拖拽信息**

   通过**拖拽方式**，可以将网页中的内容粘贴到 Lattics 文档中，反之，也可以**将 Lattics 文档中的内容拖拽到网页应用**中，比如 Notion，ReadWise 等，以及许多 AI 应用，比如 DeepSeek，ChatGPT 中

5. 多端同步

   在配置了第三方同步之后，在 Web app中所访问的网页记录，书签等内容将会自动同步，实现多端同步

6. **翻译网页（待开发）**

   将网页内容翻译为指定的语言
