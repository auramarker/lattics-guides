最常使用的内容组织方式是层级式的，比如 文件夹 -- 文件， 项目 -- 文件， 通常是通过层级式的文件夹 或者 目录树的方式进行管理。

Lattics 提供了三种层级式内容管理方式，每种都非常便捷和实用：

1. 项目大纲

   每个项目都有一个项目大纲。在项目大纲中，可将内容以自顶向下的目录树结构进行管理。Lattics 提供的是无限层级的大纲，即在大纲中可创建 4层，5层甚至更多层级，这为管理非常复杂和庞大的项目带来可能；

   项目大纲视图的宽度可自由调节。鼠标移上大纲和正文之间的分界线时，会变为左右箭头，此时可拖拽移动分界线，改变大纲的视图宽度。

   **提示：**可使用鼠标拖拽移动一篇或多篇文章，将它们置于大纲中的任意位置和层级

   **快捷键**： 选中一篇文章，当文章标题高亮时，使用 Tab 键可将该文章缩进一层，Shift + Tab 则可将该文章提升一层；

2. 思维导图

   思维导图是图谱中的一个功能。其原理与项目大纲一样，只是呈现的形式不同。它以直观的自左向右的图形化方式呈现出内容之间的层级关系，比项目大纲更容易看清楚内容之间的逻辑结构，也更容易调整内容在层级中的位置。

   思维导图上的节点都可以拖拽移动，当 A 节点移到 B 节点的右侧时，B 节点右侧会出现一个紫色的连接线，此时如果松开 A 节点，则 A 节点就会成为 B 节点的子节点。 右键点击思维导图的节点，会出现节点的更多操作，可编辑节点的正文内容，也可为节点设置颜色、添加Tag、也可删除节点。

   **提示：**思维导图的节点位置会与项目大纲中的节点位置实时同步。

   **快捷键：**点击节点，当其高亮时，使用 Ctrl + E / Cmd + E，可快速打开节点的正文进行编辑

3. 多项目层级

   当项目越来越多时，可对项目进行层级管理。 项目的多层级方式和项目大纲中的文章层级一样，可以拖拽移动项目所在的位置和层级，也可以使用同样的快捷键 Tab 缩进一层，Shift + Tab 则可将项目提升一层
