Lattics 的设计理念与提供许多提供多 Tab 交互方式的笔记应用并不相同，为了最大的保持写作的专注力，Lattics 在主界面中始终仅保持显示一篇文章的内容，点击文章中的引用，卡片库、图谱，时间线，都会以浮动窗口展示其内容，并不会全部遮挡原文或原界面

如果需要额外打开多篇文章或者多个项目，则需要借助 Lattics 所提供的“独立窗口”功能

Lattics 为多处提供了“独立窗口”：

1. 当在项目列表选中一个项目，在项目大纲中选中一篇文章，可以通过右键菜单，将它们在独立窗口中打开，如下图所示：

   <Image src="/images/multi-wins/No-277-image.png" width={80}></Image>

2. 当在卡片弹窗编辑器中打开了一篇文章，那么可以通过其右上角的独立窗口图标，将该卡片或文章在独立窗口中打开

   <Image src="/images/multi-wins/No-403-image.png" width={80}></Image>

3. 也可以将卡片库、图谱、时间线在独立窗口中打开

   <Image src="/images/multi-wins/No-503-image.png" width={80}></Image>


通过独立窗口，就可以同时打开多个项目，多个文章，以及多个卡片库、图谱和时间线，这些窗口都可以独立的调整尺寸和放置的位置，这样就可以很轻松的组合出一个非常个性化，并且非常聚焦写作的工具组合了，比如，可以同时打开主界面 + 卡片库 + 时间线，可以一边写作，一边查看卡片库的资料，一边查看时间线的事件，如下图所示。这种组合方式，明显比多 Tab 的交互更加容易聚焦写作，并且可以享受多个工具同时展示的强大便利
