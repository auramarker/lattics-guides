在管理内容时，经常需要把内容添加到不同的项目或界面中，Lattics 提供了几种非常方便的所见即所得的拖拽功能：

1. 从项目大纲、卡片库、搜索结果中拖拽到正文 或图谱中

   <Video src="/images/dragtoarticle.mp4" width={80}></Video>

   把项目大纲、卡片库、搜索结果中的内容拖拽到正文中，会自动变成标题引用；把它们拖拽到图谱中，会变成项目或者 Tag 图谱中的一个节点。

2. 从图谱中拖拽到项目大纲、正文中

   <Video src="/images/graphToTree.mp4" width={80}></Video>

   把图谱中的一个节点拖拽到项目大纲中，会成为大纲中的一篇文章；拖拽到正文中会变成标题引用。

3. 把正文中的段落拖拽到卡片库和图谱中

   把正文中的一个文本块拖拽到卡片库中会变成一个卡片； 拖拽到图谱中会变成一个节点。同时，正文中的块会变成全文引用。

4. 从卡片库拖拽到项目大纲中

   <Video src="/images/cardtotree.mp4" width={80}></Video>

   把卡片库中的一个卡片拖拽到项目大纲中，可以将卡片转为文章，反之，把项目大纲的文章拖拽到卡片库中，则把文章转为卡片；

5. 从一个项目大纲中拖拽到另一个项目大纲中

   <Video src="/images/treeToTree.mp4" width={80}></Video>

   把一个项目大纲中的文章拖拽到另一个项目的大纲中，会移动文章的位置。
