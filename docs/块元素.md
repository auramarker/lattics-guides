与传统的写作和笔记应用不同，Lattics 在编辑中采用了 块元素 的方式。每个段落就是一个块，每个块都可以拖拽移动。

Lattics 支持的块元素包括：正文、标题、待办事项、有序列表、无序列表、引用、分割线、图片、表格、代码块、数学公式等

<Video src="/images/block.mp4" width={80}></Video>

在编辑中，正文可以随时输入。而如果要添加其他的块元素，则需要在一个空行中输入 / 语法，就会展开块元素的菜单，点击其中一个块元素即可完成添加操作。也可使用键盘的上下方向键选择，也可输入块元素后的字母快速定位。

要拖拽块元素，需要将鼠标移到块元素上，在块元素的左侧出现操作图标后，用鼠标点击并拖拽该图标即可移动块元素。在拖拽块元素时，会出现一条紫色指示线，用于指示块元素将会插入的位置。

**提示：**点击块元素的操作图标，会出现不同的操作菜单。比如对于文本块，可以将它们转换为其他文本格式，可以设置对齐方式、缩进、行距等。

### 图片

图片是一类仅次于文本的常用块元素，有一些特殊操作需要专门介绍：

1. 添加图片的方式除了 / 菜单，还可直接 复制/粘贴，或者从电脑文件夹中拖拽图片文件到正文中；

2. 点击图片，图片被高亮后，可以在底部为其添加标题

3. 可以拖拽图片的四角，缩放大小

4. 点击图片的拖拽图标，可以调整图片的显示宽度

### 表格

Lattics 现在采用的表格是基于 Markdown 语法的表格，因此功能非常简单，不过依然可以完成一些基本的需求。比如增加、删除表格的行和列，编辑表格中的文字

后续，Lattics 将会增强表格功能，请大家耐心等待。

### 代码块

Lattics 支持的代码块可以自动检测数十种常见编程语言，并高亮显示该语言的关键词。如果自动检测不正确，还可以自己设置正确的语言。

**提示：**Lattics 支持从 JetBean、VSCode 中复制代码，粘贴到正文中后直接变为代码块。
