Lattics 提供了标签来对文章、卡片和文件进行多重分类管理。其中包括两种标签：普通标签 和 层级标签。普通标签 就是常见的 #Tag 的方式，而层级标签则是 **#Fruit/Apple/RedApple** 的方式，可以创建一种层级式的分类，这对具有多层类别的内容管理非常合适。

在 Lattics 中，为文章、卡片 和 文件 标记标签有两种方式：

1. **在扩展信息界面中的 Tag 区标记**

  <Image  src="/images/tag_in_extension.jpg" width={80}/>

2. **在文章、卡片的正文中，使用 # 作为语法词直接添加 Tag**，可以在正文的任何位置添加
   <Image  src="/images/tag-in-text.jpg" width={80}/>
   点击标签，即可打开图谱界面，展示标签下的文章、卡片和文件
   <Video src="/images/click_tag.mp4" width={80}></Video>
