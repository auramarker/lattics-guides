在学术论文写作或者专业期刊文章中，常常需要多栏排版。

Lattics 提供了两种多栏排版的方法：

1. **手动多栏排版：**

   你可以通过拖拽段落、图片、表格等块元素，将它们拖拽到另一个块元素之后或之前，即可创建出多栏模式。在这种方式下，你可以将多张图片、文本段落、表格并列排放，也可以在左栏或右栏中上下排放图片、文本段落、表格。还可以通过左右移动栏与栏之间的分界线，调节每栏的宽度，可以组合出非常漂亮的排版方案。

   这种方式是完全通过手动控制完成的。它的优点是非常灵活，缺点是如果要对许多内容都要放入分栏中，就会需要非常繁杂的手动操作了，因此适合用于需要并列显示多张图片或表格时使用

   **提示：**为了排版美观，并且便于导出 PDF，Doc 文档，Lattics 限制最多只能手动创建三栏。

2. **自动多栏排版：**

   你可以通过 / 菜单 创建一个多栏，或者选中部分内容，然后使用 Shift + Ctrl/Cmd + 2 快捷键创建。以这种方式创建的多栏，将会以高度最小的方式自动布局其中的内容，并不能进行手动的布局。取消自动多栏排版的方式是，鼠标移到多栏排版的左上角，点击最左侧的单栏图标，即可将多栏恢复为单栏排版。

   你也可以在样式模版中，为这种多栏排版设置背景色、边框样式、上下边距，分栏的数量，以及各栏之间的间距。分栏数量默认支持 2 栏，可切换为 3 栏

   这种自动多栏排版的方式，尤其适合绝大部分正文内容都需要以多栏方式排版的场景，比如学术论文。它会自动布局内容，并且在导出 PDF 和 Word 文档时，也会为每页自动安排合适的多栏内容。它的缺点则在于不能手动干预，并且它的内容会先在左栏显示内容，然后在右栏显示，当文本内容很多时，在 Lattics 的编辑器中可能会不适合阅读，因为 Lattics 的编辑器并不分页，可能需要先看完左栏内容，然后在折头回到文章顶部阅读右栏内容，

   因此，这种自动多栏排版方式，强烈建议在你已经完成了内容写作和检查之后，需要导出为 PDF 和 Word 文档时，再将所需要的内容设定为多栏模式
