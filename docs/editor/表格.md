表格是文档应用中经常使用的功能，除了能够整齐且有条理的展示数据之外，也需要兼具美观性和强大的编辑能力，Lattics 提供的表格，兼具了这些能力

1. **添加表格**

   与 Lattics 的其他元素添加方式一样，在正文中输入 /  符号，就可以在上下文菜单中找到表格选项，为文章添加表格了

   Lattics 也支持直接粘贴 Excel， Google Sheet， Numbers 等常用表格应用的表格数据，在它们中复制后，可以在 Lattics 中粘贴，即可添加表格
2. **编辑表格**

   鼠标移动到表格之上，双击表格，或者点击表格右上角的图标，即可打开表格编辑器，对表格内容和样式进行编辑

   Lattics 的表格支持富文本编辑，可以选中部分文字，点击右键，在右键菜单中设置它们的颜色，字体，对齐方式等，也可以在单元格中输入图片、链接、甚至可以输入 @ 引用和参考文献

   <Video src="/images/table_1_at.mp4" width={80}></Video>
3. **合并单元格**

   选中多个单元格，点击右键，可在右键菜单中设置单元格的合并，或取消合并
4. **冻结行列**

   点击表格的行首，列首，或任意一个单元格，点击右键，可在右键菜单中设置冻结，即可冻结相应行列
5. **切换表格模版**

   Lattics 提供了多种常用表格，包括三线表、财务报表，库存表、资产负债表、对账单等，可以一键切换
6. **自定义表格样式**

   你也可以自己定义表格的表头行、总计行，第一列，最后一列、第一列头单元格，最后一列头单元格，第一列总计单元格、最后一列总计单元格，并可设置它们的边框样式和颜色，以及表格交替背景色，制作出一个独具特色并非常精美的表格

   <Video src="/images/table_2_template.mp4" width={80}></Video>
7. **可交互图表**

   文不如表，表不如图。如果要更好的展示数据，Lattics 还提供了可交互图表的功能，可一键将数据表格转换为精美的可视化图表，比如堆叠图、折线图、饼图等，具体可参考“可交互图表”一节的介绍
8. **交叉引用**

   Lattics 的表格还支持交叉引用，这对写作学术论文非常方便，具体使用方法可参考“交叉引用”一节介绍
