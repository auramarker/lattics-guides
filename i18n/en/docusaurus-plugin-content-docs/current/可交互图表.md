The best way to display data is through charts. Lattics provides a very rich and powerful chart templates, including Column, Bar, Stacked, Line, Pie , Donut, Rose, Scatter, Bubble, Linear Regression, Exponential Regression, Radar charts, Candlestick charts, etc. These charts can be switched with just one click, which is very convenient.

1. **Add and switch charts**

   Before using interactive charts, you need to create a table first. For how to create a table, please refer to the guide in the "Table" section.

   After creating a table, open the table editor and click the + icon at the top to select a chart to create. The chart data comes from the table by default, so if you modify the data in the table, the data in the chart will also be updated in time. You can create multiple charts for a table, and switch different chart templates freely. Whatever chart is displayed in the table editor, it will also be displayed in the body of the document after exiting the table editor. Therefore, the display of the table editor is also synchronized with the display in the body document.

2. **Set the chart style**

   Lattics provides the function of customizing chart styles. You can define the font size, color, orientation of X-axis and Y-axis, legend position and line color of the chart. It is very powerful and easily to design a unique and beautiful chart

   <Video src="/images/chart_2.mp4" width={80}></Video>
3. **View data interactively**

   The interactive charts of Lattics are more powerful, you can view specific data values directly on the chart and quickly filter the data to be displayed.

   <Video src="/images/chart_3.mp4" width={80}></Video>

Lattics' interactive charts are drawn in real time based on the data in the table. Therefore, you only need to modify or add the data in the table to quickly update the chart. This will improve the efficiency of heavy data analysis, consulting reports and professional paper.
