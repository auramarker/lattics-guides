Lattics provides a convenient multi-column layout for images and texts, which can arrange multiple pictures and text paragraphs side by side, or up and down in one column. You can combine the typography in an elegant way.

<Video src="/images/duoColumn_en.mp4" />

The width of each column can be adjusted by drag <Highlight color="Yellow">the dividing line</Highlight> between the columns.

Note: In order to facilitate the export of PDF and Doc documents, Lattics can only have three columns.
