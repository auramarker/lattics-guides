Lattics 提供了多种导出和分享的功能：

<Image src="images/export_en.png" />

1. 导出为 PDF、Doc 文件

   单篇文章和整个项目都可以导出为 PDF 和 Doc 文件。导出时还可以设置页码样式，是否导出脚注，以及页眉页脚等实用功能。

   导出项目时，还可以选择自动生成文档目录，以及自动生成每篇文章的标题。

2. 导出为 PNG 图片

   Lattics 支持把文章和项目导出为适合手机和桌面电脑查看的图片。

3. 导出为 Markdown 和 TXT 文件

   有时，可能需要将内容迁移到其他的笔记软件中，则可以使用 Markdown 或者 TXT 文件方式导出内容。这些导出方式可能会损失一些样式效果，也会损失一些高级的功能，比如卡片引用，图文多栏等等。

4. 导出为 Lattics 项目文件

   Lattics 将来将会提供把项目中的文章、文件、卡片、图片、图谱等数据整体打包为一个项目文件，该文件可以发送给其他人，使用 Lattics 打开后依然可以保持同样的项目大纲、卡片引用、思维导图、鸟瞰图等图谱。 导出为项目文件时，可以设置加密口令，只有加密口令才能打开浏览。此功能将会在未来提供，敬请期待...

5. 幻灯片演示

   开启幻灯片演示功能后，可以把 Lattics 写作的内容直接用于线下演讲和在线课程介绍。此功能将会在未来提供，敬请期待...

6. 分享在线链接

   Lattics 将会提供需要授权的链接分享功能，以方便在线多人协作。
