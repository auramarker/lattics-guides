Lattics is fully equipped with keyboard shortcuts so you can do everything you need without ever touching your mouse.

1. **Project Outline**
   
   |          | Windows          | MacOS           |
   |----------|------------------|-----------------|
   | New      | Enter            | Enter           |
   | Delete   | Ctrl + D         | Cmd + D         |
   | Remove   | Ctrl + Shift + D | Cmd + Shift + D |
   | Previous | Up arrow         | Up arrow        |
   | Next     | Down arrow       | Down arrow      |
   | Indent   | Tab              | Tab             |
   | Un-nest  | Shift + Tab      | Shift + Tab     |

2. **Main Interface**
   
   |                                      | Windows          | MacOS           |
   |--------------------------------------|------------------|-----------------|
   | Create a card                        | Ctrl + N         | Cmd + N         |
   | Global Search                        | Ctrl + Shift + S | Cmd + Shift + S |
   | Expand / Draw back the expand info   | Ctrl + Shift + I | Cmd + Shift + I |
   | Expand / Draw back the card library  | Ctrl + L         | Cmd + L         |
   | Expand / Draw back the project lists | Ctrl + P         | Cmd + P         |

3. **Knowledge Graph**

   |                                      | Windows                | MacOS                  |
   |--------------------------------------|------------------------|------------------------|
   | Adjust display portion of the board  | Two-finger zoom in/out | Two-finger zoom in/out |
   | Create a node                        | Enter                  | Enter                  |
   | Create a child node                  | Tab                    | Tab                    |
   | Delete the node                      | Ctrl + D               | Cmd + D                |
   | Remove the node                      | Ctrl + Shift + D       | Cmd + Shift + D        |
   | Open the editor                      | Ctrl + E               | Cmd + E                |
   | Switch the view                      | Ctrl + M               | Cmd + M                |
   | Expand / Draw back the card library  | Ctrl + L               | Cmd + L                |
   | Expand / Draw back the project lists | Ctrl + P               | Cmd + P                |

4. **Editor(main editor and pop-up editor)**
   
   |                                    | Windows                | MacOS                  |
   |------------------------------------|------------------------|------------------------|
   | Adjust display portion of the text | Two-finger zoom in/out | Two-finger zoom in/out |
   | Bold                               | Ctrl + B               | Cmd + B                |
   | Italic                             | Ctrl + I               | Cmd + I                |
   | Underline                          | Ctrl + U               | Cmd + U                |
   | Strikethrough                      | Ctrl + D               | Cmd + D                |
   | Highlight                          | Ctrl + M               | Cmd + M                |
   | Select all                         | Ctrl + A               | Cmd + A                |
   | Copy                               | Ctrl + C               | Cmd + C                |
   | Paste                              | Ctrl + V               | Cmd + V                |
   | Cut                                | Ctrl + X               | Cmd + X                |
   | Delete                             | Ctrl + D               | Cmd + D                |
   | Revoke                             | Ctrl + Z               | Cmd + Z                |
   | Context menu of style              | Ctrl + T               | Cmd + T                |
   | Formatter                          | Ctrl + F               | Cmd + F                |
   | Heading                            | Ctrl + 1-6             | Cmd + 1-6              |
   | BlockQuote                         | Ctrl + Shift + .       | Cmd + Shift + .        |
   | Bulleted list                      | Ctrl + Shift + 8       | Cmd + Shift + 8        |
   | Numbered list                      | Ctrl + Shift + 9       | Cmd + Shift + 9        |
   | Code block                         | Ctrl + Shift + \       | Cmd + Shift + \        |
   | Find and replace                   | Ctrl + S               | Cmd + S                |
   | Open / Close the expand info       | Ctrl + I               | Cmd + I                |
