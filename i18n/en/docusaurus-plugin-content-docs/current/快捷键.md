Lattics is fully equipped with keyboard shortcuts so you can do everything you need without ever touching your mouse.

1. Project Outline

   Adjust the text level:

   - Indent: Tab

   - Un-nest: Shift + Tab

2. Main Interface

   Create a card: Ctrl/Cmd + N

   Expand / Draw back the card library: Ctrl/Cmd + L

   Expand / Draw back the project lists: Ctrl/Cmd + B

3. Knowledge Graph

   Adjust display portion of the board: Two-finger zoom in/out

   Create a card: Ctrl/Cmd + N

   Edit the text: Ctrl/Cmd + E

   Delete the text/card: Ctrl/Cmd + D

   Switch the view: Ctrl/Cmd + M

   Expand / Draw back the card library: Ctrl/Cmd + L

   Expand / Draw back the project lists: Ctrl/Cmd + B

4. Editor(main editor and pop-up editor)

   Adjust display portion of the text: Two-finger zoom in/out

   Select all: Ctrl/Cmd + A

   Copy: Ctrl/Cmd + C

   Paste: Ctrl/Cmd + V

   Cut: Ctrl/Cmd + X

   Delete: Ctrl/Cmd + D

   Revoke: Ctrl/Cmd + Z

   Context menu of style: Ctrl/Cmd + T

   Formatter: Ctrl/Cmd + F

   Open / Close the expand info: Ctrl/Cmd + I
