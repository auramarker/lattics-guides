Lattics is fully equipped with keyboard shortcuts so you can do everything you need without ever touching your mouse.

1. Project Outline
   New: Enter

   Delete: Ctrl/Cmd + D

   Remove: Ctrl/Cmd + Shift + D

   Previous/Next: Up/Down arrow

   Adjust the text level:

   - Indent: Tab

   - Un-nest: Shift + Tab

2. Main Interface

   Create a card: Ctrl/Cmd + N

   Global Search: Ctrl/Cmd + Shift + S

   Expand / Draw back the expand info: Ctrl/Cmd + Shift + I

   Expand / Draw back the card library: Ctrl/Cmd + L

   Expand / Draw back the project lists: Ctrl/Cmd + P

3. Knowledge Graph

   Adjust display portion of the board: Two-finger zoom in/out

   Create a node: Enter

   Create a child node: Tab

   Delete the node: Ctrl/Cmd + D

   Remove the node: Ctrl/Cmd + Shift + D
   
   Open the editor: Ctrl/Cmd + E
   
   Switch the view: Ctrl/Cmd + M

   Expand / Draw back the card library: Ctrl/Cmd + L

   Expand / Draw back the project lists: Ctrl/Cmd + P

4. Editor(main editor and pop-up editor)

   Adjust display portion of the text: Two-finger zoom in/out

   Bold: Ctrl/Cmd + B

   Italic: Ctrl/Cmd + I

   Underline: Ctrl/Cmd + U

   Strikethrough: Ctrl/Cmd + D

   Highlight: Ctrl/Cmd + M

   Select all: Ctrl/Cmd + A

   Copy: Ctrl/Cmd + C

   Paste: Ctrl/Cmd + V

   Cut: Ctrl/Cmd + X

   Delete: Ctrl/Cmd + D

   Revoke: Ctrl/Cmd + Z

   Context menu of style: Ctrl/Cmd + T

   Formatter: Ctrl/Cmd + F

   Heading: Ctrl/Cmd + 1-6

   BlockQuote: Ctrl/Cmd + Shift + .

   Bulleted list: Ctrl/Cmd + Shift + 8

   Numbered list: Ctrl/Cmd + Shift + 9

   Code block: Ctrl/Cmd + Shift + \

   Find and replace: Ctrl/Cmd + S

   Open / Close the expand info: Ctrl/Cmd + I
