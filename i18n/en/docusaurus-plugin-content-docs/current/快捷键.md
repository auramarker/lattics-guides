为了提高一些常用操作的效率，Lattics 提供了如下一些快捷操作：

1. 项目大纲的快捷键

   调整文章所在层级： 

   缩进一级： Tab

   提升一级： Shift + Tab

2. 主界面的快捷键：

   创建卡片： Ctrl + N / Cmd + N

   展开 / 收起卡片库：Ctrl + L / Cmd + L

   展开 / 收起项目列表： Ctrl + B / Cmd + B

3. 图谱的快捷键

   调节画布的显示比例： 双指放大 / 缩小

   创建新卡片：Ctrl + N / Cmd + N

   编辑正文： Ctrl + E / Cmd + E

   删除文章/卡片： Ctrl + D / Cmd + D

   移除文章/卡片： Ctrl + Shift + D /  Cmd + Shift + D （是否需要？）

   切换视图：Ctrl + M / Cmd + M

   展开 / 收起卡片库： Ctrl + L / Ctrl + L

   展开 / 收起项目列表： Ctrl + B / Cmd + B

4. 编辑器中的快捷键（包括主编辑器和弹窗编辑器）

   调节正文内容的显示比例： 双指放大 / 缩小

   全选： Ctrl + A / Cmd + A

   复制： Ctrl + C / Cmd + C

   粘贴： Ctrl + V / Cmd + V

   剪切： Ctrl + X / Cmd + X

   删除： Ctrl + D / Cmd + D

   撤销： Ctrl + Z / Cmd + Z

   样式上下文菜单：Ctrl + T / Cmd + T

   格式刷：Ctrl + F / Cmd + F

   打开 / 关闭扩展信息：Ctrl + I  / Cmd + I
