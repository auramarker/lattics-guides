title: Goals and Task Management
---

Lattics provides goal setting for each article and each project, with deadlines and target word counts.

<Image src="/images/goal/No-139-image.png" width={35} widthSm={75}></Image>

Open the statistics interface in the lower right corner of the Latitcs, you can check the recently set goals, as well as the number of words written each day, the count of added words and cards in the last 30 days, and the list of recently modified articles. This information can help you understand recent writing and task status.
