Tables are a frequently used feature in document applications. In addition to being able to display data neatly and in an organized manner, they also need to be both aesthetically pleasing and powerfully editable. The tables provided by Lattics have these capabilities.

1. **Add a table**

   Just like adding other elements in Lattics, enter the / in the text, and you can find the table option in the context menu to add a table in the article

   Lattics also supports directly pasting table data from common table applications such as Excel, Google Sheets, Numbers, etc. After copying them, you can paste them in Lattics to add a table
2. **Edit the table**

   Move the mouse on the table, double-click it, or click the icon in the upper right corner of the table, to open the table editor

   Lattics tables support rich text editing. You can select some text, right-click, and set their color, font, alignment, etc. in the right-click menu. You can also enter pictures, links, and even @ citations and bibliography in its cells.

   <Video src="/images/table_1_at.mp4" width={80}></Video>
3. **Merge cells**

   Select multiple cells and enable right-click menu to merge them
4. **Freeze rows and columns**

   Click the beginning of a row, column, or any cell in the table, right-click and choose the freeze option in the context menu to freeze the corresponding row or column.
5. **Switch table template**

   Lattics provides a variety of commonly used tables, including 3 lines, Annual Report, Inventory, Balance, Consultant, etc., which can be switched with one click easily
6. **Customize table styles**

   You can also define the table Header Row, Total Row, First Column, Last Column, First Header Cell, Last Header Cell, First Total Cell, Last Total Cell, and set their border style and color, as well as the table alternate background color, to create a unique and very beautiful table

   <Video src="/images/table_2_template.mp4" width={80}></Video>
7. **Interactive charts**

   Text is not as good as a table, and a table is not as good as a chart. If you want to better display data, Lattics also provides interactive charts, which can convert data tables into exquisite visual charts, such as Stacked, Line, Pie, etc., for details, please refer to the guide of the "Interactive Charts" section.
8. **Cross-reference**

   Lattics tables also support cross-references, which is very convenient for writing academic papers. For specific usage, please refer to the guide of "Cross-reference" section.
