When conducting ancient character research, you often need to use ancient characters that are not available in modern fonts in your papers, such as Chinese oracle bone inscriptions, ancient Egyptian characters, etc. To enter these characters, you usually need to use inline images, that is, insert images between the characters of the text.

For example, the oracle bone script <InlineImage src="/images/inline-img/No-99-image.png"></InlineImage> means "star", <InlineImage src="/images/inline-img/No-172-image.png"></InlineImage> means "cow", <InlineImage src="/images/inline-img/No-245-image.png"></InlineImage> means "bean".

Adding inline images is very simple. After capturing and copying an ancient character screenshot, just use the Ctrl / Cmd + V shortcut key to paste it in a paragraph.

In order to make the inline image and the text content harmonious and beautiful, Lattics has realized that the size of the inline image can automatically match the font size of text, that is, when the text font size increases, the inline image automatically increases, and when the text font size shrinks, the inline image automatically shrinks. Lattics limits the height of the inline image to 120% of the font height, that is, 10% more than the text height above and below, so as to reserve some margin when capturing inline images, which is convenient for capture it.

**Notice:**

**Inline math equation** and **inline code**, do not need this method,  because Lattics has offered the features of inline math equation and inline code, If you want to know more about them, please read the "Math Equation" and "Code Block " of the Lattics's Guides
